# Task f01: Add slugify utility

## Goal
In `src/strings.py`, implement a new function `slugify(text: str) -> str`.
It should:
- Convert text to lowercase.
- Replace whitespace and punctuation with single hyphens.
- Strip leading and trailing hyphens.

Use feature-workflow: write a test first in a new test file, then implement the minimal code.
Do NOT edit existing test files.
